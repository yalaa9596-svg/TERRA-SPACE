1. High-Level Project Summary

Terra Space is a bilingual (Egyptian Arabic & Global English) mobile and web precision-agriculture platform built by Team NOVERA for the Field Shift: Adapting Farms with NASA challenge. Smallholder farmers often suffer preventable crop loss from ill-timed irrigation during extreme weather shifts, botanical-family rotation conflicts, and delayed diagnosis of plant diseases. Terra Space integrates live NASA POWER agroclimatology telemetry, Open-Meteo 48–72h forecasts, PlantDoc visual disease triage, GPS distance matching to the nearest agricultural engineer, and a voice-first AI advisor—empowering farmers everywhere to adapt fields quickly and connect with local specialists.

2. Detailed Project Description

What It Does & How It Works

  • NASA 5-State Irrigation Advisor: Evaluates real-time satellite climate indicators and root-zone soil moisture against crop-specific thresholds to issue one of five actionable daily states: Urgent Irrigation, Irrigation Needed, Do Not Irrigate (≥5 mm rain forecasted within 48h), Heat / Cold Wave, or All Good, alongside estimated daily irrigation volume in L/m².
  • Smart Crop Rotation Engine: Checks climatic suitability and prevents consecutive planting of conflicting botanical families (e.g., Poaceae → Poaceae such as Maize after Wheat, or Solanaceae → Solanaceae) while recommending climatically compatible alternatives across Egyptian governorates, global agricultural hubs, and custom GPS coordinates.
  • PlantDoc AI Vision Doctor & Auto-Escalation: Accepts camera or gallery leaf photos and classifies conditions across the 27 PlantDoc disease/healthy classes via multimodal Gemini Vision (with deterministic local PlantDoc fallback offline). Whenever model confidence drops below 75%, infection severity is high, or the crop lies outside PlantDoc's 11-crop leaf scope (e.g., Wheat, Cotton, Olive), Terra Space automatically escalates the case to the nearest matched agronomist.
  • Geo-Matched Agronomist Portal (Haversine): Ranks agricultural engineers across 5 specialties (Plant Pathology, Field Crops, Vegetables, Fruits & Orchards, Irrigation & Soil) using Haversine great-circle distance from the farmer's coordinates. Engineers can register, inspect live NASA telemetry for their assigned farmer, and send treatment advice directly.
  • Local & Global Bilingual Voice Companion: Supports one-tap switching between Local Mode (Egyptian Arabic, RTL layout, ar-EG speech recognition and ar-EG-ShakirNeural neural speech) and Global Mode (English, LTR layout, en-US STT and en-US-GuyNeural TTS), backed by BM25 RAG and persistent per-farmer chat memory.

Tools, Languages, Hardware & Software Stack

  • Frontend Mobile & Web App: Flutter / Dart (Material UI, Provider state management, speech_to_text, flutter_tts, image_picker, geolocator, shared_preferences, url_launcher), packaged as both an Android release APK (52.2 MB) and a responsive Web build.
  • Backend API & Storage: Python 3 with FastAPI, Uvicorn, HTTPX/Requests, SQLite (smartcrop.db for users, consultations, escalations, and persistent chat/memory), rank-bm25 (BM25Okapi), and edge-tts.
  • Hardware Requirements: Standard Android smartphone (camera + microphone + GPS optional) or any desktop/mobile web browser; Python 3 backend server with internet access for NASA POWER, Open-Meteo, Gemini API, and Edge-TTS.

5. Use of Artificial Intelligence / Super Intelligence (AI/SI) Disclosure

In full compliance with the 2026 NASA Space Apps AI/SI guidelines, Team NOVERA discloses all AI tools used and all affected components:

  • Google Gemini REST API (Gemini Flash-Lite / Vision & Chat models): Used inside smart_crop_backend/vision_engine.py to visually classify uploaded plant photos against PlantDoc categories and inside voice_assistant_engine.py to generate concise farmer advice grounded strictly in retrieved NASA telemetry and BM25 agronomic chunks. Prompts explicitly forbid inventing telemetry numbers.
  • BM25 Sparse Retrieval (rank-bm25): Indexes curated agricultural knowledge docs and PlantDoc disease metadata (rag_engine.py) with colloquial Egyptian-to-agronomic synonym expansion so LLM answers cite grounded practices.
  • Neural Speech Synthesis (edge-tts) & Speech-to-Text: Used in tts_service.py and voice_service.dart to convert verified text responses into spoken Egyptian Arabic (ar-EG-ShakirNeural) or English (en-US-GuyNeural) audio output (Audio acknowledgement: all spoken responses synthesize verified text generated from NASA/PlantDoc backend modules and include descriptive text alongside audio).
  • AI-Assisted Development Disclosure (Code/Data): AI coding assistants assisted with software refactoring, bilingual localization scaffolding, and test automation. Every line was verified against live API responses, backend integration suites (test_core.py), and Flutter widget tests (widget_test.dart).
  • NASA Branding Compliance: No NASA logos, flags, insignias, or mission identifiers were generated or modified by AI. Terra Space uses an original custom sprout-and-orbit logo designed independently.
